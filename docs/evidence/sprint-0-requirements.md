# Project Requirements

## Identified Problem or Need

Report writing is very time consuming, it has to be rewritten multiple times for each student and copy and pasting can get pretty tiresum. If only there was a way to allow teachers to generate personalised reports quickly without needing to copy and paste templates.


## End-User Requirements

A typical end-user for this system is my Dad who is a primary school teacher.

- Simple UI.
- Streamlined for speed.
- Effcient use of elements.
- Apply HSS Report writing style guide and adhere to the rules detailed within this document.
- Use example comments to generate new comments using the appropriate tone.
- Use correct NZ grammar.

Note: The five numbers will need to match the following achievement descriptors: emerging, developing, consolidating, proficient and exceeding.

## Proposed Solution

A streamlined user interface that keeps student personal data secure. It should allow teachers to choose from a set range of number that represents performance for reading, writing, maths and general comment. There should also be an option to edit the generated response at the end of the questionare to allow for any final tweaks.
